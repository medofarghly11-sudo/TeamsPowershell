# TeamsPowershell
Repo for teams powershell scripts

1. Phone Numbers Reassignment
Here is a list of the scripts currently in this repo
ReassignPhoneNumbersStepOne.ps1
ReassignPhoneNumbersStepTwo.ps1
Those two scripts are written to solve one main issue. In case you want to switch your users from a license to another license (for example F3 to E3) all phone numbers will be unassigned. What those scripts will do is make a list of all the users and their numbers. Then after you change the licenses run the second script to return all phone numbers as they were.
